# AGENTS.md

## Что это

Демон, который переносит файлы между медиа-томами, чтобы на источниках
оставалось свободное место. Ничего не переносится без одобрения в
веб-интерфейсе. Go 1.27, chi, html/template + pico/htmx, `slog`, YAML-конфиг.

## Сборка и тесты

```sh
make check    # gofmt, go vet, сборка, тесты
make test
go test ./e2e/ -v -count=1
```

## Структура

```
cmd/diskd/        флаг --config, сигналы, запуск и остановка демона
internal/app/     сборка: конфиг, cron, сторож конфига, веб-сервер
internal/config/  схема конфига, парсер размеров и длительностей, атомарное
                  хранилище конфига (его подменяет сторож при перечитывании)
internal/disk/    Probe (свободное место по Statfs), обход папок, перемещение
internal/scheduler/ план, состояние, выполнение, откат, state.json, history.jsonl
internal/web/     интерфейс и API
e2e/              сквозной тест
```

## Границы слоёв

- `config` ничего не знает про файловую систему.
- `disk` ничего не знает про план и состояние.
- `scheduler` не знает про HTTP: у него нет представления о веб-интерфейсе.
- `web` не ходит в файловую систему: только `scheduler` и `disk`.

## Грабли, на которые уже наступали

- **Свободное место — это `Bavail`, а не `Bfree`.** `Bfree` включает блоки,
  зарезервированные под root, и демон под непривилегированным пользователем
  их не использует.
- **`http.Server.Shutdown` ждёт 5 секунд**, если клиент оставил соединение
  в состоянии `StateNew`. Остановка веб-сервера ограничена по времени
  (`httpShutdownTimeout`), после чего соединения закрываются принудительно.
- **Каждая страница шаблона — свой набор.** Все страницы определяют
  `content`, и в одном наборе победила бы последняя разобранная.
- **Формы не вкладываются друг в друга.** В таблице плана форма отката лежит
  в ячейке, а не внутри другой формы.
- **Один файл — одна операция.** `os.Rename` не работает между томами:
  `EXDEV` означает копирование с последующим удалением источника.
- **Источник удаляется только после успешного копирования.** Оборванная
  копия оставляет источник на месте.
- **Перед повтором приёмник удаляется целиком.** Дописывать partial-копию
  нельзя: получится битый файл.
- **Карта в Go обходится в случайном порядке.** Папки всегда берутся через
  `Config.Sorted()`, иначе план меняется от запуска к запуску.
